# Как внести вклад

Спасибо за интерес к проекту.

## Процесс

1. Форкните репозиторий и создайте ветку от `main`: `git checkout -b feature/описание`.
2. Следуйте существующему стилю кода (Python 3.10+, приоритет стандартной библиотеки).
3. Добавьте или обновите тесты для изменённой логики.
4. Убедитесь, что весь набор тестов проходит: `python3 -m pytest`.
5. Откройте Pull Request с описанием: что меняется, зачем, как проверено.

## Принципы проекта

- **Стандартная библиотека прежде всего.** Новые runtime-зависимости — только с обоснованием в PR.
- **Никаких секретов в коде.** Токены, пароли — только через `.env`.
- **Юридическая корректность.** Не добавляйте в интерфейс и тексты обещания юридического результата (см. `docs/legal-disclaimer.md`).

## Отчёты об ошибках

Используйте Issues с шаблоном Bug report. Приложите шаги воспроизведения и ожидаемое/фактическое поведение.

# Пакет модулей Докуматики

Дополнительные документы, которые продаются **строкой в комплекте 799 ₽** — тому
tрафику, который уже пришёл за политикой конфиденциальности. Предельная
стоимость модуля ≈ 0: тот же движок шаблонов, генерация DOCX, платёжный контур.

Источник: отчёт 08 (волна 1, агент Modul). Все кандидаты прошли фильтры формулы
отбора: обязательность по закону, видимость снаружи, отсутствие бесплатного
субсидируемого.

## Ключевые инсайты

- **Согласие на рассылку — скрытая дыра базового комплекта.** ФАС подтвердила:
  согласие на обработку ПД ≠ согласие на рекламу (кейсы: Совкомбанк 400 тыс.,
  Билайн 700 тыс. ₽). У покупателей Докуматики этого документа нет.
- **Cookie-баннер стал сильнее.** РКН изменил практику на opt-in (кнопка
  «Отклонить», блокировка скриптов до согласия). Старые баннеры «продолжая
  использование…» стали нарушением — это апсейл к существующим покупателям.
- **546-ФЗ (сертификаты в карточках с 01.09.2026)** — свежий SEO-инфоповод
  с нулевой конкуренцией.

## Приоритет реализации

1. Согласие на рассылку (закрывает дыру комплекта, крупный штраф)
2. Cookie opt-in (апсейл к существующим, свежая практика РКН)
3. Публичная оферта (якорь для интернет-магазинов)
4. Условия доставки/возврата (логично с офертой)
5. Блок 546-ФЗ (SEO-инфоповод к 01.09.2026)

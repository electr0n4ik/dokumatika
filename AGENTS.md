## Что это

`dokumatika.ru` — бесплатный генератор политики конфиденциальности по 152-ФЗ плюс
платный комплект из 7 документов за 799 ₽ через Robokassa. Бесплатная часть
приводит поисковый трафик, платная зарабатывает.

Продукт держится на одном факте: **с 01.09.2025 согласие на обработку
персональных данных должно быть отдельным документом**, поэтому одной политики —
того, что дают бесплатные генераторы конкурентов, — по закону уже мало.

Состояние: код готов, 472 теста зелёные, 25 страниц. **Не выкачен, домен не
зарегистрирован.**

## Команды

```bash
make run        # dev-сервер: PYTHONPATH=src python3 -m app.server
make test       # PYTHONPATH=src python3 -m pytest tests -q
make check      # ruff + синтаксис + тесты, перед каждым коммитом
make preflight  # готовность к бою: реквизиты, ключи, права на var/
```

Порт 8081 должен совпадать в трёх местах: `.env`, конфиг nginx, unit systemd.

## Стек — не пересматривать

Python 3.10+, **только стандартная библиотека**, ни одной pip-зависимости в
рантайме. `http.server.ThreadingHTTPServer`, SQLite, серверный рендер HTML
функциями (шаблонизатора нет), ванильный JS без сборщика. Ноль внешних запросов
со страниц.

Решение продиктовано сервером 2 vCPU / 4 GB, где живут ещё несколько проектов.
Flask, FastAPI, Jinja, React, Postgres предлагать не нужно.

## Инварианты — нарушение ломает проект

1. **Ответы визарда и реквизиты пользователя НИКОГДА не уходят на сервер.**
   Документы собираются в браузере. Сервер хранит по заказу только код продукта,
   сумму, email доставки и статус. Код, отправляющий ответы визарда на бэкенд, —
   регресс: он делает владельца оператором чужих персональных данных со всеми
   обязанностями по хранению, защите и удалению.
2. **Статус «оплачено» ставит только ResultURL** после проверки подписи на
   Password #2. SuccessURL не подтверждает ничего — его открывает кто угодно с
   любыми параметрами.
3. **Сумма берётся из каталога продуктов, а не из запроса.** Иначе подмена
   `OutSum` оплатит комплект за рубль.
4. **`canceled` и `failed` обратимы в `paid`.** Покупатель платит, колбэк
   задерживается, покупатель жмёт «вернуться в магазин» — необратимая отмена
   означала бы «деньги у нас, документов нет».
5. **`InvId` уникален и возрастает.** Повтор даёт ошибку 40 у Robokassa, и
   покупатель не сможет заплатить.
6. **Движок документов реализован дважды** — на Python и на JS — и обязан давать
   идентичный результат. Поэтому язык условий нарочито примитивен: `{field, op,
   value}`. Любой «полноценный DSL» немедленно разведёт две реализации.
   Паритет проверяет `tests/test_js_parity.py`.
7. **Весь текст интерфейса и документов — по-русски.**
8. **Правка `styles.css` или `js/*.js` требует нового `ASSET_VERSION`** — статика
   отдаётся с кэшем на год по версионированному URL.
9. **Никогда не заявлять** «юридическая консультация» (допустимо только
   отрицание), «одобрено Роскомнадзором», «гарантия отсутствия штрафов», «100%
   соответствие», «закрывает статью N КоАП». Это ст. 5 ФЗ «О рекламе».
10. **Все юридические цифры — из `docs/fakty-152-fz.md`.** Факта нет в файле —
    значит, его нет на сайте. Ничего не додумывать: это юридический продукт.

## Где что лежит

| Путь | Что |
|---|---|
| `src/app/server.py` | HTTP: маршруты, статика, лимиты, graceful shutdown |
| `src/app/handlers.py` | построение ответов без HTTP — логика тестируется без сокетов |
| `src/app/robokassa.py` | подписи, форма оплаты, разбор ResultURL, фискальный чек |
| `src/app/documents/` | шаблоны документов и вопросы визарда — **данными, не кодом** |
| `src/app/web/pages/*.py` | страница = модуль с объектом `PAGE` и чистой `build(ctx)` |
| `src/static/js/` | визард, генерация DOCX, оплата — всё в браузере |
| `docs/fakty-152-fz.md` | единственный источник юридических цифр |
| `docs/zamechaniya-k-dorabotke.md` | 43 незакрытых замечания с разбором |
| `deployment/ROLLOUT.md` | развёртывание с нуля, `bootstrap.sh` |

Новая страница = файл в `src/app/web/pages/` с объектом `PAGE` плюс строка в
`pages/__init__.py`. Роутер и `sitemap.xml` соберутся сами. Функция `build`
обязана быть чистой: без БД и сети, иначе страницу нельзя протестировать.

## Тесты

472 теста, ~3 секунды, **без сети и без запуска сервера** (кроме
`test_server.py`, который поднимает его на случайном порту). Фикстуры — в
`tests/conftest.py`.

Часть тестов — контрактные: они пробегают по всем страницам сразу и проверяют
длину title, единственность H1, наличие FAQ и крошек, отсутствие запрещённых
формулировок и двойного экранирования. Добавили страницу — эти тесты её проверят
автоматически.

Тест `test_js_parity.py` требует Node; без него пропускается.

## Стратегический контекст: проект как измерительный прибор

К 26.07.2026 для следующих проектов проверено 75 идей, 41 разобрана насквозь —
**не выжила ни одна**. Полный разбор в `../../исследования/`, начинать с
`СВОДКА.html` или `05-20-agentov-i-glavnyy-vyvod.md`.

Причина структурная, а не в качестве идей: все они отбирались под допущение
«канал привлечения — SEO в Яндексе», и это допущение **ни разу не измерено**.
Оно бинарное — если новый домен берёт органику, жива вся скамейка отложенных
идей; если нет, не жива ни одна.

Докуматика даст первое честное число: сколько поискового трафика берёт новый
домен в конкурентной российской нише за 60–90 дней после выкатки.

**Практическое следствие для агента:** если поступает задача «начать следующий
проект», сначала проверить, выкачена ли Докуматика и есть ли данные Метрики за
квартал. Без этого числа расчёт по любому новому проекту — гадание, и это уже
подтверждено двумя независимыми прогонами.

Второе, что подтвердилось: проект живёт за счёт **протухающего слоя** —
законодательство меняется само, обновление сводится к правке
`docs/fakty-152-fz.md`, копия конкурента устареет вместе с КоАП. Ни одна из 41
отклонённой идеи такого слоя не имела: почти все копировались за месяц и стоили
ноль у конкурентов. **Это главный критерий для следующей ниши.**

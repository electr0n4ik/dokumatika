# Политика безопасности

## Сообщение об уязвимости

НЕ создавайте публичный Issue по уязвимостям. Сообщите напрямую владельцу репозитория (через GitHub Security Advisory или контакт в профиле). Укажите описание, шаги воспроизведения и потенциальное влияние.

## Область

- Платёжный контур (подписи колбэков, подмена сумм, идемпотентность).
- Хранение пользовательских токенов (шифрование, доступ).
- Внедрение в шаблоны документов (экранирование пользовательского ввода).

## Что мы обещаем

- Подтверждение получения в течение 72 часов.
- Оценка и план исправления в течение 14 дней для подтверждённых уязвимостей.

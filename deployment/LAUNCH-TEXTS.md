## 2. Яндекс.Метрика — цели

Создать счётчик, вписать `METRIKA_ID` в `.env`. Затем настроить цели.

### Цель 1: Оплата начата
- Название: `Оплата начата`
- Тип: JavaScript-событие
- Условие: `url содержит /pay/` ИЛИ событие `ym('reachGoal','pay_start')`
- Ценность: воронка

### Цель 2: Оплата завершена (конверсия)
- Название: `Оплата завершена`
- Тип: JavaScript-событие
- Условие: событие `ym('reachGoal','pay_success')` на странице успеха
- **Это главная конверсия. Отметить как «Конверсионная цель»**
- Ценность: 799 ₽

### Цель 3: Документ сгенерирован (бесплатно)
- Название: `Документ сгенерирован`
- Тип: JavaScript-событие
- Условие: событие `ym('reachGoal','doc_generated')` при скачивании DOCX
- Показывает вовлечённость бесплатного генератора

### Цель 4: Визит на комплект
- Название: `Просмотр комплекта`
- Тип: Просмотр страниц
- Условие: `url содержит /komplekt/`

### Цель 5: Глубокий визит (вовлечённость)
- Название: `Глубокий визит`
- Тип: Количество просмотров ≥ 3

### Воронка продаж
1. Визит → 2. Просмотр комплекта → 3. Оплата начата → 4. Оплата завершена

**Важно:** встроенная воронка в `/admin/` работает без Метрики — Метрика нужна
для SEO-аналитики (источники, запросы, поведение), не для учёта заказов.

## 3. Первый пост-запуск контент

### 3.1. Текст для vc.ru / Хабр (инфоповод + продукт)

```
Заголовок: С 1 сентября 2025 года одной политики конфиденциальности на сайте
недостаточно. Собрал генератор комплекта документов 152-ФЗ

Тело:
Проверьте свой сайт: откройте футер и найдите согласие на обработку
персональных данных как ОТДЕЛЬНЫЙ документ. Не пункт в политике — отдельную
страницу с формой согласия.

Если его нет — вы в той же лодке, что и большинство владельцев сайтов в РФ.
С 01.09.2025 вступили в силу поправки: согласие на обработку ПД должно быть
отдельным документом. Бесплатные генераторы политики конфиденциальности дают
только политику — согласие придётся собирать вручную.

Штраф по ст. 13.11 КоАП — до 300 тыс. ₽ для должностного лица, до 700 тыс. ₽
для юрлица. При этом отсутствие документа видно с улицы: открыл сайт — нет
согласия — состав нарушения готов.

Я собрал Докуматику — конструктор, который по анкете из 10–15 вопросов
generирует комплект:
— политика конфиденциальности (бесплатно)
— согласие на обработку ПД
— согласие на рекламную рассылку
— политика cookie
— уведомление в Роскомнадзор
— оферта, возврат, приказ об ответственном

Бесплатный генератор политики — без регистрации. Полный комплект — 799 ₽,
DOCX сразу в браузере, ничего не уходит на сервер.

Это типовые шаблоны, а не юридическая услуга. Если у вас сложный случай —
нужен юрист. Но для типового сайта/магазина/лендинга этого достаточно,
чтобы закрыть формальные требования.

Ссылка: dokumatika.ru

Буду рад обратной связи: что неудобно, чего не хватает в анкете.
```

## Что блокирует старт (всё — за владельцем, ~117 минут)

Это единственная часть, которую нельзя делегировать скрипту или агенту: нужен
человек с паспортом, картой или доступом в чужой личный кабинет.

### Этап 1. Домен и DNS (15 мин, до всего)
- [ ] **1.** Купить домен у регистратора (reg.ru, timeweb, nic.ru). Варианты:
  `dokumatika.ru` (проверить свободность), `dokumatika.рф`, `dokumatika.site`.
- [ ] **2.** Направить DNS: A-запись `@` → IP VPS #2, CNAME `www` → домен.
  DNS расходится 15–60 мин (до 24 ч).

### Этап 2. Сервер (2 мин + ожидание)
- [ ] **3.** На VPS #2 от root:
  ```bash
  apt update && apt install -y git
  git clone https://github.com/electr0n4ik/dokumatika.git /root/dokumatika
  bash /root/dokumatika/scripts/bootstrap.sh dokumatika.ru
  ```
- [ ] **4.** Заполнить реквизиты продавца в `/etc/dokumatika/.env`
  (ФИО, ИНН, e-mail, город — как в «Мой налог»).
- [ ] **5.** Проверить: `curl -I https://dokumatika.ru` → 200.

### Этап 3. Robokassa (45 мин + 1–3 дня модерации)
- [ ] **6.** Завести аккаунт Robokassa, подать магазин на модерацию.
- [ ] **7.** Вписать три URL в «Технические настройки» (Result/Success/Fail).
- [ ] **8.** Разрешить «Робочеки СМЗ» в «Мой налог» и включить в кабинете Robokassa.
- [ ] **9.** Вписать пароли в `.env`, прогнать тестовый платёж, затем боевой на 799 ₽ самому себе.

### Этап 4. Аналитика и регистрация (50 мин)
- [ ] **10.** Подтвердить домен в Яндекс.Вебмастере, добавить sitemap.xml.
- [ ] **11.** Завести счётчик Метрики, вписать `METRIKA_ID` (опционально).
- [ ] **12.** Подать уведомление в Роскомнадзор (pd.rkn.gov.ru, бесплатно, Госуслуги).

Настроить отслеживание:

- **Цели Метрики:** оплата начата, оплата завершена, документ скачан.
- **Запросы для отслеживания позиций:** «политика конфиденциальности генератор»,
  «согласие на обработку персональных данных скачать», «документы 152-ФЗ для
  сайта», «комплект документов для сайта купить».
- **Фиксация:** позиции и визиты на неделях 4, 8, 12 → записать в
  RESEARCH-TRACKER.md (хронология решений).
